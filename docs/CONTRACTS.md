# 合同边界

当前默认引擎：见 [ENGINE-API.md](ENGINE-API.md)，实体以 `qingtian_engine/db.py` 和 `service.py` 为准。

知识检索：仓库 `contracts/` 与安装包 `qingtian_kb.resources.contracts` 是 stdin JSON 请求/响应合同。

`schemas/`、`examples/`、`qingtian_core/resources/schemas/` 是 **legacy 实验室**合同，不是新引擎 HTTP schema。[旧说明](legacy/CONTRACTS.md)。不要混用数据库或状态名。
